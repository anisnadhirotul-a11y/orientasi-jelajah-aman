Cache-segar adalah data yang masih tersimpan dan belum melewati batas waktu 30 menit, jadi aplikasi tidak perlu mengambil data lagi dari internet. Sedangkan cache-basi adalah data yang sudah melewati batas waktu tersebut, tetapi masih bisa ditampilkan saat tidak ada koneksi internet. Kalau first-run offline, aplikasi belum punya data yang tersimpan dan internet juga tidak tersedia, sehingga informasi cuaca belum bisa ditampilkan. Menurut saya, label status data itu penting supaya pengguna tahu apakah informasi yang dilihat masih terbaru atau data lama, jadi tidak salah memahami kondisi cuaca yang ditampilkan.
